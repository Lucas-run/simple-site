Coloque o primeiro seu ambiente e segundo o pacote.

Create a realistic overhead product image using two references:

* Image A is the empty environment scene with only the model's hands visible
* Image B is the package reference

Use Image A as the main base for the scene. Preserve the exact same environment,
background, surface, framing, lighting, camera angle, hand-position style, and skin
tone. Maintain the nail color.

## TASK

Add the small package from Image B into the model's hands so the model is naturally
holding it in the scene.

## PACKAGE AND HANDS

* The package must be small and clearly visible in the hands
* Show the FRONT side of the package
* The shipping label must face the camera and be readable and fully visible from the
  front
* Center and position the package naturally
* The hands must hold the package firmly and realistically from both sides, like a
  natural product presentation
* Preserve the package's black plastic material, proportions, folds, and front-label
  appearance from the reference
* Do not change the package design, redesign the label, or replace the package

The final image should look like the model is presenting the package for a TikTok Shop
product reveal, with the package clearly shown in front view.

## SCENE LOCK

* Keep the camera fixed in a top-down overhead angle
* No camera movement
* No extra objects
* No product outside the package
* No background changes

## FINAL QUALITY

Create a clean, realistic overhead product image with the model naturally holding the
small package in both hands and clearly showing its front side and label against the
empty environment.

* No distorted hands
* No extra fingers
* No deformed package
* No label changes
