Use Image 1 as the base scene. Use Image 2 ONLY as the clothing reference.

## TASK

Replace the clothing item currently inside the transparent package with ALL clothing
items shown in Image 2.

## IMPORTANT

* Preserve the environment from Image 1 exactly
* Preserve the bed and blanket exactly
* Preserve the camera angle, lighting, composition, and perspective exactly
* Preserve the plastic package exactly
* Preserve all hands exactly as they appear in Image 1
* Do not create a new scene or modify the room
* Do not modify the packaging position

## CLOTHING REPLACEMENT

* Remove only the clothing item currently visible inside the package
* Place ALL clothing items from Image 2 inside the same package
* Replicate the clothing exactly as shown in Image 2
* Preserve the same color, fabric, design, print, and proportions
* Do not redesign or creatively interpret the clothing

## PACKING AND FOLDING

* If Image 2 contains multiple items, pack all pieces together inside the same
  transparent package, neatly like a real online fashion order
* Fold the clothing naturally and professionally for e-commerce presentation
* Arrange all pieces so they fit realistically and remain fully inside the package
* When possible, fold and position prints, graphics, logos, and important design
  elements so the main front design remains clearly visible through the packaging
* Maintain realistic fabric folds and packaging reflections

## FINAL QUALITY

* Ultra-photorealistic
* Natural shadows
* Realistic transparent plastic and fabric texture
* Realistic product-photo appearance
* No AI artifacts

## EXCLUSIONS

* No added text or logos
* No watermarks
* No filters
* No stylization
